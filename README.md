## 반별 패들렛 연결 (ai-lesson1, ai-lesson2, ai-lesson3)

- 선생님 설정은 주소 끝에 `#teacher`를 붙여 열면 보입니다. 예) `https://kyeongsoon.github.io/info/ai-lesson1/#teacher`
- 반 수를 넣고 '반 수만큼 줄 만들기' 또는 '+ 반 추가'로 반마다 패들렛 주소를 넣습니다.
- 설정에서 만들어지는 링크
  - 전체 반 공용 링크(`?pb=…&pl=…&pn=…`, 주소 형식이 다르면 `?padlets=…`): 학생이 활동 3에서 자기 반을 골라 제출. 링크가 잘리면 학생 화면에 다시 들어오라는 안내가 나옴
  - 반별 링크(`?padlet=…&class=…`): 반이 정해져 있어 고를 필요 없음
- 또는 `ai-lesson1/index.html` 스크립트 맨 위의 `PADLETS`에 `["반 이름", "패들렛 주소"]`를 적어 두면 링크 없이도 항상 적용됩니다.
- 적용 순서: 학생용 링크 → 코드의 `PADLETS` → 그 기기에 저장한 목록

## 2차시 활동 2 티처블 머신

- 기본: 티처블 머신 **포즈 프로젝트**를 바로 열어 웹캠으로 바른 자세 / 바르지 않은 자세 데이터를 모으고, 테스트 미션 5개로 평가합니다.
- 웹캠을 쓸 수 없을 때: 사이트의 ‘웹캠이 안 될 때 · 그림 파일로 하기’에서 아래 그림 묶음을 이미지 프로젝트로 학습합니다.

### 바른 자세 학습 그림 (ai-lesson2/posture)

- `posture-good-20.zip`(바른 자세 20장), `posture-bad-20.zip`(바르지 않은 자세 20장), `posture-test-5.zip`(테스트 5장)
- 실제 사진이 아닌 그림이라 티처블 머신 **이미지 프로젝트**로 학습합니다. 두 클래스 모두 교실·집·도서관 배경을 고르게 섞었습니다.
- 테스트 정답: 1 바른 자세, 2 바르지 않은 자세(구부정함), 3 바른 자세, 4 바르지 않은 자세(늘어짐), 5 바르지 않은 자세(고개 숙임)
